=== BACKEND ===

=== backend/package.json ===
Define as dependências e scripts do servidor:
express: framework web
cors: permite requisições do frontend
piexifjs: extração de metadados EXIF das fotos
Scripts para iniciar o servidor (npm start ou npm run dev)

=== backend/photos.json ===
Base de dados em formato JSON que armazena todos os dados das fotografias (metadados, descrições, caminhos).

=== backend/server.js ===
Coração do backend. Servidor API REST que:
Serve ficheiros estáticos (HTML, imagens)
GET /api/photos: lista todas as fotos
POST /api/photos: adiciona/atualiza fotos
DELETE /api/photos/:id: elimina fotos
GET /api/exif: extrai metadados EXIF usando exiftool (câmara, ISO, abertura, etc.)
Gere o ficheiro photos.json como base de dados

=== frontend/src/components/AddEditModal.jsx ===
Modal para adicionar/editar fotos que:
Formulário com todos os campos (título, categoria, local, descrição)
Botão "Ler Dados EXIF" que extrai metadados automaticamente
Campos EXIF são read-only (só preenchidos via extração)
Reutilizável para adicionar e editar

=== frontend/src/components/AuthModal.jsx ===
Modal de autenticação simples:
Password hardcoded: 12345
Controla acesso às funções de gestão (adicionar/editar/eliminar)

=== frontend/src/components/PhotoGrid.jsx ===
Grelha de fotos que:
Exibe miniaturas em layout responsivo
Implementa pesquisa e filtro por categoria
Mostra mensagem quando não há fotos

=== frontend/src/components/PhotoModal.jsx ===
Modal de visualização detalhada que mostra:
Imagem em grande
Metadados EXIF (abertura, ISO, velocidade, focal)
Informações (local, data, hora, câmara, lente)
Botões de editar/eliminar (se autenticado)
Modo ecrã inteiro
